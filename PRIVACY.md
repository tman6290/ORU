# Privacy

ORU sends no usage data. It has no analytics, no telemetry and no crash
reporting, and it does not check for updates.

- Speech recognition, the everyday model (Ollama) and speech output run on
  this machine by default.
- API keys are encrypted with the operating system keychain and stay in the
  main process.
- Voice, transcripts, prompts and replies leave the machine only when you turn
  on a cloud provider in Settings. They then go to that provider and nowhere
  else.
