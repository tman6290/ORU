# Resume a phase

Read `docs/PROGRESS.md`. Find the phase in progress and the newest session log entry.

1. Tell me in five lines or fewer: what is done, what is left, and the next step.
2. Open the prompt file for that phase in `prompts/` and read the tasks and acceptance checks that remain. Skip the parts already done.
3. Plan the remaining work and wait for my approval.
4. Continue under the session protocol in `CLAUDE.md`.

Do not redo finished work. Do not re-read docs the remaining tasks don't need.
