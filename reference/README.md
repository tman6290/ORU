# GUI reference

Drop your reference images for the ORU interface in this folder (PNG, JPG or WebP).

- Name them so the order is clear: `01-main-view.png`, `02-orb-closeup.png`, `03-panels.png`.
- Add a line per image to the list below saying what you like in it. One sentence each is enough.
- Claude Code treats these as a base for layout and mood and then designs ORU's own look from `docs/DESIGN.md`.

Git ignores the images in this folder, so they stay on your laptop and out of the public repo.
